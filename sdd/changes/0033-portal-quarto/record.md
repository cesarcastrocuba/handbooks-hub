## Implementation

The candidate stages an isolated Quarto website and renders with Quarto 1.11.9. Validated catalog
values bind to packaged templates with HTML escaping and newline encoding, preventing raw-fence
or shortcode injection. Guides are five ordinary packaged Markdown pages. Library links, declared
editions and search/category/title/latest controls remain, with a generated category/title cover.
Native Quarto supplies site navigation, guide search, light/dark toggle, canonical/social metadata
and favicon. The living Design page is generated from the packaged tokens, not a private preview.

The book's exact Sass and CSS factories are shared, with portal-only geometry in design.py.
No private copy of the theme is introduced. The shared Sass explicitly disables Cosmo's Google
Fonts import: the browser proof caught this import despite the self-hosted family setting. The
packaged library filter is shared inline by both engines; no hosted script or motion library is
added. Motion comes from the shared reduced-motion-guarded native CSS.

Quarto's sitemap used staging filesystem modification times despite SOURCE_DATE_EPOCH. The builder
parses the XML and omits optional lastmod fields rather than inventing dates. It never edits rendered
HTML. Repeated builds compare every resulting file byte for byte. Output publication is atomic;
failed renders leave neither a partial destination nor private staging. Renderer children receive
no GitHub authentication token. Online verification remains a separate, unchanged gate.

## Retained behavior and limits

The existing single-page templates remain because they are still deployed. Extracting the shared
filter resource preserves the legacy index bytes exactly. The Pages workflow builds the candidate
for verification but uploads only the unchanged legacy _site. Portal previews are included in the
template edition-preview CI artifact; fixture books are clearly marked and never deployed.

The catalog has no per-book licence field. The candidate links to the handbook's declaration and
never assigns the platform licence to an unknown book. Adding licence metadata to the catalog is
outside this renderer change. The existing legacy phone overflow is measured and recorded, not
silently rewritten while claiming byte parity.

See evidence.md for commands and inspection. STATUS.md and docs/decisions.md are not edited.
