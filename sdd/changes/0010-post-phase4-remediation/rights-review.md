# Third-party rights review — bundled render resources

**Status:** Closed for toolkit `0.5.0` and later under `HUB-DEC-020`.
**Date:** 2026-11-08
**Scope:** files under `tools/src/handbook_toolkit/render_data/` added after the Phase 4 close, and
what the `v0.2.0` sample release carries from them. This is an engineering record, not legal advice.

## Questions raised and how they were closed

The owner chose on 2026-11-08 not to carry these risks and asked for alternatives.

1. **Cascadia Code metadata (R2).** The license field inside each TTF (name ID 13) opened with
   "Microsoft supplied font... Any other use is prohibited" before a license based on the OFL.
   **Replaced** by JetBrains Mono 2.304. Its TTF files are byte-identical to `fonts/ttf/` in the upstream
   `JetBrainsMono-2.304.zip`, and its name table and `OFL.txt` state plain OFL 1.1.
2. **`reference.docx` provenance (R3).** 14 of 16 parts matched the Pandoc 3.10 default, and Pandoc is
   GPL-2.0-or-later. **Replaced** by a document generated by `tools/scripts/generate_reference_docx.py`.
   None of its package parts match the Pandoc default. It keeps the author's fonts, sizes, colors and
   spacing. It still uses 38 style identifiers that Pandoc looks up by name, in a similar order, and
   `Abstract`, `AbstractTitle` and `FootnoteBlockText` repeat Pandoc spacing or indent values.
3. **Liberation Sans (R5).** Builds took it from the environment. **Now bundled** at 2.1.5 from the
   upstream `liberation-fonts-ttf-2.1.5.tar.gz`, with its `LICENSE` stored as `OFL.txt`. Its name table
   and license state OFL 1.1. The DejaVu fallbacks were removed from the styles.

Selawik (R1) had no open question and stays.

## Effect on published releases

A test build of the sample book with these resources embeds only Selawik, JetBrains Mono and Liberation
Sans. Published releases are unchanged. The PDFs of `v0.1.2` to `v0.2.0` embed Cascadia Code subsets, and the
DOCX editions of `v0.1.1` to `v0.2.0` were built with the replaced reference document. No legal
conclusion is drawn about those editions. Superseding or withdrawing them is an owner decision.

The same files remain in the read-only `solutions-architecture-handbook`, outside this review.
